Guides

From installing to the figures in your tax return. Step-by-step guides for each exchange are under Guides and news.

Getting started
  1. Download and install Kryptokompis (Windows or Android). Accept the terms.
  2. Data & setup → You: name on the report, and the year full FIFO starts from.
  3. Exchanges & wallets → Add exchange: connect with a read-only API key, or import the exchange's export file.
  4. Kryptokompis syncs and calculates. Check Tax report → Checks: all green means the data adds up.
  5. A licence unlocks the figures for the tax return, the PDF report and the CSV files. Not sure? Try the example data first.
Create a read-only API key

Kryptokompis never needs to trade or withdraw. Create the key with read access only:

ExchangePermissions needed
KrakenQuery Funds, Query Open/Closed Orders & Trades, Query Ledger Entries. Kraken's guide
Binance"Enable Reading" only. Leave trading and withdrawals off. Binance's guide
CoinbaseCoinbase Developer Platform: "View only", signature algorithm ECDSA. Coinbase's guide
KuCoinAPI Management → "General" only (no Trade, no Transfer). The passphrase is the one you chose. KuCoin's API only reaches the last 12 months. KuCoin's guide
Export files (no API key)
ExchangeHow to get the file
Revolut XRevolut app → Revolut X → Account statement → choose the period and Excel/CSV.
Firifiri.com → Transaksjoner → Export / Download CSV, every year you traded.
Coinbasecoinbase.com → Profile → Statements / Reports → Transaction history → CSV. One file per year is fine.
KuCoin, older yearsOrders → Spot Orders → Filled Orders → Export (tick "Show Order-Splitting"). Older years come from KuCoin support.
OthersDownload the Kryptokompis template in the app, one row per transaction, and import it.

Importing the same period again is safe - nothing is counted twice.

Entering the figures in the tax return
  1. In skattemeldingen: Finans → Virtuelle eiendeler / kryptovaluta. You can put the coins on one card, but must be able to show the total coin by coin - the PDF and CSV files do that.
  2. Enter the amounts from Kryptokompis (chapter 1 of the PDF): Formuesverdi, Skattepliktig gevinst, Fradragsberettiget tap, Andre inntekter and Forvaltningskostnader.
  3. Gains and losses go in separate fields - they are not netted.
  4. Cash on exchanges (dollars/kroner) is not a virtual asset. The balance at the turn of the year is wealth, normally a claim against the exchange. Where to report it depends on the balance, the currency and where the exchange is based. More in the guide.
  5. Keep the PDF and the CSV files. They are not submitted, but are your documentation if Skatteetaten asks.
Move your data to the phone or another PC
  1. On the PC: Data & setup → Move to another PC → Export everything. Choose a password if the API keys should come along.
  2. Send the file to the phone (email, cloud, cable).
  3. On the phone: same place → Import, pick the file and enter the password.

About Kryptokompis

Kryptokompis is made in Norway by a developer who trades crypto himself and wanted figures he could trust. More about who makes it.

  • Norwegian rules: FIFO per coin across exchanges, Norges Bank NOK rate on each transaction date, gains and losses kept apart.
  • Your data stays on your own device. API keys can only read.
  • Every report states which ruleset was used and what was assumed.
  • Not tax advice - you are responsible for your tax return. Terms
